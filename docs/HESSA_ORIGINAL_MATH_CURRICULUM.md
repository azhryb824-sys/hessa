# Hessa Original Mathematics Curriculum v1

This curriculum is original Hessa-authored instructional content. It is not a reproduction or paraphrase of a Ministry textbook.

Design references:
- Saudi national curriculum standards describe expected learning in terms of what a learner should know, understand and perform by level/grade.
- Ministry study plans establish mathematics as a core primary subject.
- Ministry basic-skills initiatives emphasize number sense and the four operations in primary mathematics.

Architecture:
grade -> domain -> unit -> skill -> prerequisites -> outcomes -> mastery checks -> adaptive next skill.

Version 1 establishes a coherent primary 1-6 spine. It is intentionally narrower than a complete commercial curriculum release: each node must later receive lesson variants, worked examples, misconceptions, intervention paths, mastery items and expert review before full production promotion.
