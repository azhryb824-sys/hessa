# Scientific-strength roadmap

Current commercial focus: primary mathematics.

Scientific quality principles:
1. Separate computation truth from language generation.
2. Diagnose misconceptions, not only correctness.
3. Require transfer across representations before mastery.
4. Use seeded question generation for reproducible evaluation.
5. Keep benchmark cases outside fine-tuning data.
6. Require >=98% deterministic-engine accuracy on supported generated cases; target 100% before declaring a skill fully verified.
7. Do not mark mastery from repeated near-duplicate questions.
8. Add human educator review for curriculum, misconception taxonomy and intervention quality.

Next depth targets: place value/regrouping verifier, decimal arithmetic/comparison, fraction multiplication/division where grade-appropriate, multi-step word problems, units/conversions, composite geometry, and explicit question metadata (skill/variant/difficulty) in persisted assessments.
