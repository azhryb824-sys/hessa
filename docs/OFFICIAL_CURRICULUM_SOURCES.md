# Official Saudi curriculum sources

Production curriculum content must originate from authorized Ministry of Education channels.

- My Courses (مقرراتي): official service for digital course copies; active Madrasati account is required.
- Madrasati: official electronic-learning platform and book catalog.
- Ain: Ministry-listed alternative channel for curricula.

The repository catalog may store public metadata discovered from official pages. It MUST NOT mark textbook body text as ingested unless the actual authorized source file/content was obtained. Authentication must not be bypassed.
